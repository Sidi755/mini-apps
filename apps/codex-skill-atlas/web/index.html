Skill、插件、工具，有什么区别？

技能 Skill：给 Codex 的工作说明，安装后在聊天里调用。

插件 Plugin：连接应用、工具或界面，在插件列表中安装和使用。

软件工具 Tool：独立程序或命令行，例如浏览器自动化工具，通常需要配置环境。

项目名称带“插件”不代表此条目本身就是插件；未收录的类型会显示空结果。

使用指南

找到技能，然后交给 Codex

  1. 描述你想做的事

    用中文、英文或技能名搜索，再按用途和来源缩小范围。

  2. 查看摘要与适用条件

    每个条目都链接到 GitHub 原文。社区技能可能需要额外工具或适配。

  3. 复制安装提示

    在 Codex 聊天中粘贴提示，先检查来源与依赖，再安装需要的技能。

摘要如何产生？

中文精选由已核实的 SKILL.md 整理。已精选内容提供中文摘要；新发现条目自动提取简介并保留原文语言，可用“只看中文摘要”筛选。原文变化时会提示中文摘要待复核。分类根据关键词生成，可在原文中核对。

开启后，打开网页及每 15 分钟检查更新；页面隐藏或断网时暂停，恢复后补查。关闭页面后停止。GitHub 限流时延后 60 分钟重试。
